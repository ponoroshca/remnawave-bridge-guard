# Как помочь проекту

- Нашли ложное срабатывание или пропущенный отказ — заведите issue с выводом
  `bridge-guard --dry-run` и сообщением сторожа (адреса можно заменить на 203.0.113.x).
- Другой DNS-провайдер — класс с методами `records()`, `remove(ip)`, `add(ip)`
  рядом с `Cloudflare` в `bridge_guard.py` и выбор по `failover.dns.provider`.
- Код: Python 3.9+, только стандартная библиотека, без внешних пакетов — так его можно
  положить на любой сервер одним файлом. Перед PR: `python3 -m py_compile *.py`
  и `bash -n scripts/*.sh`.
- Тексты сообщений — на русском, коротко и с указанием, что делать.
