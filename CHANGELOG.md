# Changelog

## 1.0.0 — 2026-09

Первый публичный выпуск.

- bridge-guard: проба каждого моста настоящим xray-клиентом (VLESS + Reality → внешний IP),
  гистерезис `fail_n`/`ok_n`, заморозка при `max_dead`, два режима переключения — DNS-пул
  (Cloudflare, `min_pool`) и хосты подписки панели, бэкап хостов перед правкой,
  Telegram с прокси, `--dry-run`, `--fake-dead`, `--status`.
- exit-probe: TCP-достижимость выходных нод с моста + контрольные точки
  «отрезан мост / нет сети / проблема ноды», подавление повторов.
- lanes-probe: все режимы подписки через мост как клиент — IP выхода, отклик, скорость.
- Установщики для хоста сторожа и для мостов, юниты systemd, документация.
