# Changelog

## 1.1.0 — 2026-09

«Поставил и забыл»:

- `bridge-guard setup` — мастер: находит профиль и мосты в панели, инбаунд и ключи Reality,
  заводит служебного пользователя в нужном сквадe, находит DNS-пул, проверяет токен
  Cloudflare и Telegram (тестовое сообщение, подбор прокси), пишет конфиг с бэкапом старого,
  прогоняет пробу через каждый мост, показывает репетицию отказа, включает таймер.
  Все ответы можно передать флагами, `--yes` — без вопросов.
- `bridge-guard doctor` — чек-лист с подсказками: конфиг и права, xray, панель и токен,
  служебный пользователь и его сквады, DNS-токен и состав пула, Telegram, проба через
  каждый мост, таймер и последний прогон, заморозка.
- `bridge-guard rollback` — вернуть хосты на исходные адреса и A-записи всех мостов,
  сбросить состояние; `--dry-run`.
- `bridge-guard status` показывает последние события.
- `bridges: "auto"` — мосты берутся из нод профиля каждый прогон.
- Хосты: `match_addresses` (список), исходные адреса запоминаются и возвращаются; при
  смерти второго моста хосты уезжают дальше без потери исходных адресов.
- Сердцебиение: `heartbeat.url` после каждого прогона и суточная сводка в Telegram.
- Установка одной строкой (`curl … | sudo bash`), `uninstall.sh`, `refresh-exit-probes`
  для всех мостов из панели, `install-exit-probe` работает из `/opt/bridge-guard`.
- Валидация формата `uuid`/`public_key`/`short_id` — с заглушками из примера сторож не запустится.

## 1.0.0 — 2026-09

Первый публичный выпуск.

- bridge-guard: проба каждого моста настоящим xray-клиентом (VLESS + Reality → внешний IP),
  гистерезис `fail_n`/`ok_n`, заморозка при `max_dead`, два режима переключения — DNS-пул
  (Cloudflare, `min_pool`) и хосты подписки панели, бэкап хостов перед правкой,
  Telegram с прокси, `--dry-run`, `--fake-dead`, `--status`.
- exit-probe: TCP-достижимость выходных нод с моста + контрольные точки
  «отрезан мост / нет сети / проблема ноды», подавление повторов.
- lanes-probe: все режимы подписки через мост как клиент — IP выхода, отклик, скорость.
- Установщики для хоста сторожа и для мостов, юниты systemd, документация.
